Conteúdo de outra origem

Sirva a demo também na porta 5600 (PORT=5600 npm run demo) e abra a página de iframe. O quadro embutido vem de outra origem, onde nenhum evento sintético do frame de cima alcançaria: os comandos viajam por postMessage até a cópia do content script que roda lá dentro.

Canvas que trata os próprios eventos

Este quadro cancela os eventos de roda, como faz um mapa. Serve para conferir que o gesto de zoom é entregue ao site em vez de rolar a página.
